外设驱动：

max30102

mpu6050
lcd

# 目标功能

## 主功能

1. 抬腕亮屏 、长时间不动自动息屏—— MPU6050中断
2. 亮度调整、可控制自动调整亮度——BH1750
3. 电池电压检测
4. 日历、时间
5. 充放电设置——TP4056
6. UI界面速度切换
7. 内置游戏
8. 首页背景切换
9. 绘图功能

## 子功能

1. 心率血氧——MAX30102
2. 步数——MPU6050加速度测量
3. 激光测距——VL53L0X
4. 光照测量——BH1750
5. 指南针功能——指南针模块

## 环境监测
1. 温湿度——SHT31
2. 角度——MPU6050pitch、roll
3. 气压、海拔——BMP280
4. 手表内部温度测量——MPU6050、MCU内部传感器

## 通讯功能(ESP8266/ESP32C3)

1. 蓝牙连接——与手机APP数据同步
2. 无线充电支持
3. OTA固件升级功能
4. 消息推送提醒（来电、短信、应用通知）
5. 音乐控制——蓝牙音乐播放控制
